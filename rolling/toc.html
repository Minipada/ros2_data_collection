  36. 20. Architecture Decision Records
    ❱
    1. 20.1. 0001 - External shipper process replaces embedded Fluent Bit
    2. 20.2. 0002 - Vector is the blessed default shipper
    3. 20.3. 0003 - Destination config: blessed set via ROS params, everything else via passthrough
    4. 20.4. 0004 - The Bridge is written in Rust (rclrs) as a contained pilot; the rest stays C++
    5. 20.5. 0005 - File uploads live in the Bridge, not the shipper
    6. 20.6. 0006 - The Bridge is a plain node, outside the lifecycle manager
    7. 20.7. 0007 - The Bridge returns to C++; the Rust pilot (ADR-0004) is reverted
    8. 20.8. 0008 - dc_util owns parameter declaration; nav2_util stays a dependency
    9. 20.9. 0009 - MCAP recording is a passthrough consumer, not a blessed Destination
    10. 20.10. 0010 - The Mission Measurement's lifecycle contract: nav2 adapter scope and Record shape
    11. 20.11. 0012 - aws_sdk_vendor fetches aws-sdk-cpp live from GitHub; the flattened-source design is rejected
    12. 20.12. 0013 - Remove the network-isolation-check CI job and vendor-network-check stage
    13. 20.13. 0014 - The Uploader runs as its own process
    14. 20.14. 0015 - Split deployment topology: the Shipper and the Uploader as separable processes
    15. 20.15. 0016 - Helm chart for the robot tier, Kustomize overlays per site/robot
